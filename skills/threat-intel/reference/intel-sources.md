## Live intelligence sources

| Source | URL | Carries | Cadence | Access method (exact) | Signal quality | Daily poll design |
|---|---|---|---|---|---|---|
| CISA KEV | [cisa.gov/kev](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) | Confirmed-exploited CVEs; authoritative triage filter | Days–weeks after exploit starts; catalog grew 20% to 1,480+ entries in 2025 | JSON: `https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json`; note some hosting IPs are rejected, so also clone the official mirror `https://github.com/cisagov/kev-data` | High reliability, medium speed (lag vs actual exploitation) | `git pull` kev-data mirror daily; diff `dateAdded` for new entries; map against per-target stack list |
| NVD API 2.0 | [nvd.nist.gov](https://nvd.nist.gov) | Full CVE corpus, CVSS, CPE | Continuous | `https://services.nvd.nist.gov/rest/json/cves/2.0` (REST; API key raises rate limit) | Complete but delayed vs vendor advisories (NVD processing backlog has recurred) | Hourly pull of `lastModStartDate` window; enrich KEV/PoC hits with CPE ranges |
| GitHub Security Advisories | [github.com/advisories](https://github.com/advisories) | GHSA records for npm/PyPI/Go/etc., often filed before NVD | Continuous | REST: `https://api.github.com/advisories` (list/filter); full DB: `git clone https://github.com/github/advisory-database` | Fast for OSS dependency vulns; GHSA is the primary machine feed for supply-chain crypto dev tooling | Poll `api.github.com/advisories?updated_since=` daily; alert on ecosystem=npm/PyPI + keywords wallet/seed/web3 |
| nomi-sec/PoC-in-GitHub | [https://github.com/nomi-sec/PoC-in-GitHub](https://github.com/nomi-sec/PoC-in-GitHub) | Auto-aggregated GitHub PoC repos per CVE, year-sliced JSON | ~hourly via Actions | `git clone https://github.com/nomi-sec/PoC-in-GitHub` → read `2026/2026.json`; or GitHub code search on CVE ID | Fastest public PoC radar; noisy (unverified PoCs) | Daily diff of current-year JSON; intersect with KEV → "exploited AND weaponized" shortlist |
| Exploit-DB | [exploit-db.com](https://exploit-db.com) | Curated historical exploits, searchsploit | Irregular | `git clone https://gitlab.com/exploit-database/exploitdb`; `searchsploit` CLI | Slow but curated; good for 1-day baselines | Weekly pull sufficient |
| Packet Storm | [packetstormsecurity.com](https://packetstormsecurity.com/files/exploit/) | Full advisories + PoCs incl. vendor-agnostic web/SCADA | Daily | Web + RSS: `https://packetstormsecurity.com/files/exploit/` and per-category feeds | High quality, near-real-time for exploit releases | RSS ingest daily |
| Project Zero 0day-in-the-wild | [googleprojectzero.github.io/0days-in-the-wild](https://googleprojectzero.github.io/0days-in-the-wild/) | Detected in-the-wild 0-days + root-cause analyses ([repo](https://github.com/googleprojectzero/0days-in-the-wild)) | Monthly-ish | Tracker + RCA markdown in repo | Highest analytical quality anywhere; shows what attackers actually use | Weekly git pull; treat every new RCA as a variant-analysis trigger |
| osv.dev | [osv.dev](https://osv.dev) | Multi-ecosystem OSS vuln DB (GHSA, PyPA, Go, Rust union) | Continuous | `POST https://api.osv.dev/v1/query` (per-package); bulk: `gs://osv-vulnerabilities` dataset | High for dependency exposure mapping of target stacks | Per-target: submit SBOM/package list once, subscribe to deltas |
| GitLab Advisory DB (GLAD) | [advisories.gitlab.com](https://advisories.gitlab.com/) | Dependency advisories incl. Composer/Conway ecosystems GitHub misses | Continuous | Web per-package: `https://advisories.gitlab.com/pkg/{ecosystem}/{package}/`; GraphQL `packageMetadataAdvisory` | Medium-high; complements GHSA | Include in weekly dependency sweep |
| Vulners | [vulners.com](https://vulners.com) | Meta-search across CVE, exploit-DB, PoCs, bulletins; scored | Continuous | API: `https://vulners.com/api/v3/search/lucene/` (API key) | Good correlation layer; commercial key required for scale | Daily lucene query for target stack keywords |
| Sonar / GitHub Security Lab | [securitylab.github.com](https://securitylab.github.com/) | Deep-dive research on OSS bug classes, CodeQL queries | Monthly | Web + advisory research posts | Low volume, very high quality — source of variant-analysis ideas | Weekly read; convert each writeup to a CodeQL/nuclei variant |
| Vendor PSIRT feeds | MSRC, Apple, Adobe, Ivanti, Fortinet, Palo Alto, Citrix, Atlassian | First-party advisories, fastest for edge/VPN products | Patch Tuesday / ad hoc | MSRC CVRF API: `https://api.msrc.microsoft.com/cvrf/v2.0/Updates`; Apple `https://support.apple.com/security` + RSS; Fortinet PSIRT RSS; Ivanti/Palo Alto/Citrix/Atlassian advisory pages have Atom/RSS | Vendor feeds beat NVD by days — critical for edge-device testing | Daily RSS poll; diff titles for the 8 vendors above |
| nuclei-templates feed | [ProjectDiscovery/nuclei-templates](https://github.com/ProjectDiscovery/nuclei-templates) | Community detection templates, many same-day for KEV adds | Multiple daily | `git clone` + watch releases; run `nuclei -tags cve` against scoped assets | Fast for known-pattern verification (not discovery) | Daily pull; run new templates only against authorized target list |
| Regional CERTs (JPCERT/CC, CSA SG, CERT-EU) | [JPCERT](https://www.jpcert.or.jp/english/), [CSA Singapore alerts](https://www.csa.gov.sg/alerts-and-advisories/alerts/) | Early exploit observations, APAC-flavored | Weekly | Web/RSS | Medium speed, high signal for Asia-region targets | Weekly sweep |
| SSD Secure Disclosure | [ssd-disclosure.com](https://ssd-disclosure.com) | Full technical writeups of disclosed vendor bugs | Monthly | Web | High quality lagging indicator of what researchers monetized | Monthly read |
| Patch-diffing blogs/newsletters | ZDI blog, [Patch-Diffing guide](https://cve-north-stars.github.io/docs/Patch-Diffing), [n-day dev workflow](https://blog.r4.dk/posts/ndaydev/) | Technique + 1-day analysis | Weekly | Web | Methodology canon + early hints of unfixed variants | Weekly read |
| rekt.news + SlowMist Hacked | [rekt.news/leaderboard](https://rekt.news/leaderboard), [hacked.slowmist.io](https://hacked.slowmist.io/) | Crypto incident archive: 2,292 events, $39B tracked | Per-incident | Web; SlowMist mid-year reports on Medium | Best-in-class for crypto post-mortems | Daily check of leaderboards; every new ≥$3M event → root-cause hunt within 24h |
| Sonatype / supply-chain research | [Sonatype 2026 report](https://www.sonatype.com/state-of-the-software-supply-chain/2026/open-source-malware) | npm malware stats: >99% of open-source malware now lands on npm | Annual + continuous blog | Web | High for dependency-campaign awareness | Feed campaign names into dep-audit rules |

**Gray-but-public markets (awareness only — provenance, functionality, and legality are unverifiable; buying or testing against them is out of scope):** 0day.today and the exploit.in forum re-list public PoCs with heavy duplication and planted backdoored "exploits"; treat as a lagging, untrusted mirror of what is already public, and never execute anything sourced from them against client infrastructure.

### Ranked TOP 10 for a web/API/crypto-target program

1. **CISA KEV JSON/mirror** — exploit-confirmed triage gate
2. **nomi-sec/PoC-in-GitHub** — fastest weaponization signal
3. **ProjectDiscovery/nuclei-templates** — turn intel into safe verification probes
4. **GitHub Security Advisories API** — dependency/supply-chain radar for crypto dev tooling
5. **SlowMist Hacked + rekt.news** — crypto incident root-cause corpus
6. **Project Zero 0days-in-the-wild RCA repo** — attacker-behavior ground truth
7. **Vendor PSIRT feeds (MSRC/Ivanti/Fortinet/Palo Alto/Citrix/Atlassian)** — beats NVD by days on edge devices
8. **osv.dev API** — per-target dependency exposure mapping
9. **Packet Storm + Exploit-DB** — curated exploit corpus
10. **Vulners API** — correlation/meta-search layer
